# Netflix Dashboard 

## Overview
This Power BI dashboard analyzes Netflix content to uncover insights about movies and TV shows, including genres, ratings, release years, and content distribution across countries.

## Tools Used
- Power BI
- Power Query
- Excel/CSV

## Features
- Movies vs TV Shows Analysis
- Content by Country
- Genre Distribution
- Release Year Trends
- Interactive Filters and Visualizations

## Conclusion
The dashboard provides a clear view of Netflix's content library and helps identify content trends and patterns.
